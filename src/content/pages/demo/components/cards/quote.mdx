# Quote card

A simple quote card with an optional attribution section. It can be centered with a prop and is intended for use in columns or with a carousel wrapper.

### Props

| Prop          | Type                       | Description                                                                           |
| ------------- | -------------------------- | ------------------------------------------------------------------------------------- |
| `center`      | boolean                    | _(optional)_ Aligns card text center, default is `false`.                             |
| `description` | string                     | _(optional)_ The second line of profile text under name.                              |
| `name`        | string                     | _(optional)_ The name displayed on the profile section.                               |
| `quote`       | string                     | The quote to be displayed in the card.                                                |
| `image`       | object                     | _(optional)_ Image data for the profile component. [See fields below.](#image-object) |
| `class`       | string                     | _(optional)_ Additional classes applied to the root `<figure>`.                       |
| _(extends)_   | `HTMLAttributes<"figure">` | _(optional)_ All standard HTML attributes for a `<figure>`.                           |

#### `image` object

- `src` — [ImageMetadata](https://github.com/withastro/astro/blob/dacebaf8df6293558091a18123aed966e4e57415/packages/astro/src/assets/types.ts#L38)  
  The imported image metadata (output from Astro's image import).
- `alt` — string  
  _(optional)_ Alt text for the image, defaults to empty string `""`.

</Markdown>

## About MDX

`astro-skeleton` uses the [@astrojs/mdx](https://docs.astro.build/en/guides/integrations-guide/mdx/) integration installed and configured in the `astro.config.mjs` config file.

### Why MDX?

MDX is a special flavor of Markdown that supports embedded JavaScript & JSX syntax. This unlocks the ability to [mix JavaScript and UI Components into Markdown content](https://docs.astro.build/en/guides/markdown-content/#mdx-features) for things like interactive charts or alerts.

If you have existing content authored in MDX, this integration will hopefully make migrating a breeze.

### Documentation

- [MDX Syntax Documentation](https://mdxjs.com/docs/what-is-mdx)
- [Astro Usage Documentation](https://docs.astro.build/en/guides/markdown-content/#markdown-and-mdx-pages)
