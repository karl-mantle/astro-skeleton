### Props

| Prop          | Type                    | Description                                                              |
| ------------- | ----------------------- | ------------------------------------------------------------------------ |
| `description` | string                  | _(optional)_ The card description or supporting text.                    |
| `heading`     | string                  | The heading displayed by the card, `<h3>`                                |
| `icon`        | object                  | Icon data for the component. [See below.](#icon-object)                  |
| `layout`      | object                  | _(optional)_ Layout data for the component. [See below.](#layout-object) |
| `class`       | string                  | _(optional)_ Additional classes applied to the root `<div>`.             |
| _(extends)_   | `HTMLAttributes<"div">` | _(optional)_ All standard HTML attributes for a `<div>`.                 |

#### `icon` object

- `name` — string  
  The icon name, either an iconify package (e.g. `material-symbols:sunny-outline`) or local name. [See below.](#useful-links)
- `size` — number  
  The same value is used for both height and width, number is in pixels.

#### `layout` object

- `center` — boolean
  _(optional)_ Aligns card text center, default is `false`.
- `direction` — "row" \| "column"  
  _(optional)_ Displays component's elements in a row or column, default is `column`.

### Useful links

- [Astro Icon](https://www.astroicon.dev/)
- [Iconify documentation](https://iconify.design/docs/)
- [Material Symbols icons reference](https://icon-sets.iconify.design/material-symbols/)

## About MDX

`astro-skeleton` uses the [@astrojs/mdx](https://docs.astro.build/en/guides/integrations-guide/mdx/) integration installed and configured in the `astro.config.mjs` config file.

### Why MDX?

MDX is a special flavor of Markdown that supports embedded JavaScript & JSX syntax. This unlocks the ability to [mix JavaScript and UI Components into Markdown content](https://docs.astro.build/en/guides/markdown-content/#mdx-features) for things like interactive charts or alerts.

If you have existing content authored in MDX, this integration will hopefully make migrating a breeze.

### Documentation

- [MDX Syntax Documentation](https://mdxjs.com/docs/what-is-mdx)
- [Astro Usage Documentation](https://docs.astro.build/en/guides/markdown-content/#markdown-and-mdx-pages)
